# Fe’ldan ot yasash, sinonim va antonimlar
## Fe’ldan ot yasash (отглагольные существительные)
Qoida: fe’l **-ние / -тие** qo‘shimchasi bilan otga aylanadi, qaramog‘idagi so‘z **родительный падеж**ga o‘tadi.
| Fe’l birikmasi | Ot birikmasi |
|---|---|
| Гарантировать равные права | Гарантирование равных прав |
| Создать механизм системы | Создание механизма системы |
| Получить знания | Получение знаний |
| Уважать личность | Уважение личности |
| Получить профессиональные навыки | Получение профессиональных навыков |
| Повышать квалификацию | Повышение квалификации |
| Развивать способности | Развитие способностей |
!! -ать/-ить → ==-ение/-ание==; -ть (получить) → ==получение==. Ikkinchi so‘z har doim ==родительный падеж== (кого? чего?).
## Sinonimlar
| So‘z | Sinonimlari |
|---|---|
| Учреждение | заведение, организация |
| Соответствие | совпадение, согласованность |
| ВУЗ | высшее учебное заведение, университет, институт |
| Развитие | прогресс, совершенствование, рост |
| Престиж | авторитет, влияние, уважение |
## Antonimlar
| So‘z birikmasi | Antonimi |
|---|---|
| трудолюбивый студент | ленивый студент |
| дисциплинированный ученик | недисциплинированный (непослушный) ученик |
| аккуратный мальчик | неряшливый (неаккуратный) мальчик |
| креативный студент | безынициативный (шаблонный) студент |
| низкий | высокий |
> Antonim topishda «не-» qo‘shimchasi yoki mutlaqo teskari ma’noli so‘z: «трудолюбивый — ленивый», «низкий — высокий».

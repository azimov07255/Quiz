# Leksika: so‘z va birikmalar (rus ⇄ o‘zbek)
## Mavzu: ta’lim va universitet
| Русский | O‘zbekcha |
|---|---|
| Независимое государство | Mustaqil davlat |
| Инициатива главы государства | Davlat rahbarining tashabbusi |
| Коренное реформирование | Tubdan isloh qilish |
| Повышение квалификации | Malaka oshirish |
| Передовые зарубежные вузы | Ilg‘or xorijiy oliy ta’lim muassasalari (OTM) |
| Престижное учебное заведение | Nufuzli o‘quv yurti |
| Огромные достижения | Ulkan yutuqlar |
| Выпускники университета | Universitet bitiruvchilari |
| Установить тесные связи с другими вузами передовых стран | Ilg‘or mamlakatlarning boshqa OTMlari bilan yaqin aloqalar o‘rnatish |
| Огромный потенциал | Ulkan salohiyat |
| Обоюдное сотрудничество | O‘zaro (ikki tomonlama) hamkorlik |
## Eslab qolish uchun
> «Огромный» = «ulkan» (достижения, потенциал). «Передовой» = «ilg‘or». «Тесный» = «yaqin». «Обоюдный» = «o‘zaro».
!! Tarjima savollari ikki yo‘nalishda keladi: ==ruscha → o‘zbekcha== va ==o‘zbekcha → ruscha==. Ikkalasini ham takrorlang.
